# 顶部样式与单页交互调整

基于 a815102，按用户提出的顶部视觉与双 Tab 简化方向调整。

- 移除双 Tab，方案列表和核验记录始终展示在同一工作页。
- 顶部使用紧凑的白底标题栏，去掉重复内边距；新建方案为次按钮，发起核验为主按钮，复用现有 --ty-* Token。
- 发起核验改为独立弹窗。从方案行打开时自动带入对应方案；顶部入口支持先选择方案。
- 无方案时提供空状态和新建入口。提交成功后关闭弹窗，返回记录查看执行进度；取消不创建任务。
- 保留方案编辑弹窗、单根类型正式字段、冻结快照、无分类数据阻断和部分异常状态。

验证：npm run lint、Node+tsx 运行现有 19 项测试、npm run build、git diff --check 均通过。构建保留主 bundle 超过 500 kB 的提示。

真实 Chromium 验证：无方案发起→新建方案、方案行带入、抽样核验完成（有异常）且一致率 95.8%（46 / 48）、指定 ID 去重后完成、无分类范围时禁用、取消不提交、提交关闭弹窗。1024×768、1280×720、1440×900 无页面横向溢出及弹窗越界。刷新后的控制台无错误。
