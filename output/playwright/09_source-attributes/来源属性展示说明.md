# 来源属性展示调整

2026-09-08，基于 b62c51f。本轮只补充来源定义展示与草稿保存，不调整目标字段转换、同步执行或一致性核验规则。

## 展示约定

- 来源表：支持一个或多个来源表；参数未返回显示“未返回”；明确返回空表集合显示“无直接来源表”，适用于无直接物理表的虚拟属性。
- 属性类别：硬属性、扩展属性、虚拟属性；独立于文本、数值、日期、枚举等数据类型，不按字段名前缀推断类别。
- 是否多值：明确区分是、否、未返回。批量列表以“多值”“单值”压缩显示。
- 枚举定义：明确区分有、无、未返回；有枚举时可展开查看定义编码、名称及已返回选项的编码、名称。不会把已返回选项数量声明为完整总量。
- 来源定义只读，随来源属性选择联动。单个新建/编辑与批量内的单字段配置共用展示组件。
- 批量列表采用紧凑摘要；展开枚举不触发整行勾选。
- 单个和批量保存草稿时保留来源元数据副本；历史字段没有副本时，新参数不默认成否。

## 接口边界

用户已确认 PLM 支持返回这些参数。原型使用 `sourceTables`、`attributeKind`、`isMultiValue`、`hasEnumDefinition`、`enumDefinition` 表达它们，实际接口字段名与枚举值仍需对接映射。这不是对现有 PLM API 字段名的确认。

示例覆盖硬属性、扩展属性、多值枚举和虚拟属性无来源表。所有表名以 `example_` 开头，单字段区域标注“示例元数据”、批量界面标注“原型示例数据”，不代表真实数据库表或真实属性类别。

多值与枚举的展示不代表目标端已增加集合存储、枚举转换或集合比对能力；这些处理仍沿用已有映射逻辑。
